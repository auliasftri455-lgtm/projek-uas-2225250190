Topik 1

Persamaan Kuadrat

Persamaan kuadrat adalah persamaan polinomial berderajat dua dengan satu variabel yang memiliki bentuk umum:

ax² + bx + c = 0, dengan a ≠ 0

1. Rumus Kuadratik (Rumus ABC) & Diskriminan

Akar-akar persamaan kuadrat dapat dicari menggunakan rumus ABC berikut:

x₁,₂ = (-b ± √D) / 2a   di mana   D = b² - 4ac

2. Sifat Akar Berdasarkan Nilai Diskriminan (D)

  • D > 0 : Memiliki dua akar real yang berbeda (x₁ ≠ x₂).
  • D = 0 : Memiliki satu akar real kembar (x₁ = x₂).
  • D < 0 : Tidak memiliki akar real (akar imajiner/kompleks).

Contoh Pembahasan:

Tentukan akar-akar dari persamaan x² - 5x + 6 = 0.

Diketahui: a = 1, b = -5, c = 6.
D = (-5)² - 4(1)(6) = 25 - 24 = 1 (D > 0, dua akar real berbeda).
x₁ = (5 + √1) / 2 = 6 / 2 = 3
x₂ = (5 - √1) / 2 = 4 / 2 = 2

Topik 2

Barisan & Deret Aritmatika

Barisan aritmatika adalah barisan bilangan dengan selisih (beda) yang tetap antara dua suku yang berurutan. Sedangkan deret aritmatika adalah penjumlahan dari suku-suku pada barisan aritmatika.

Rumus Suku ke-n (Uₙ)

Uₙ = a + (n - 1)b

a = suku pertama, b = beda (U₂ - U₁)

Rumus Jumlah n Suku (Sₙ)

Sₙ = (n / 2) × (2a + (n - 1)b)

atau Sₙ = (n / 2) × (a + Uₙ)

Contoh Pembahasan:

Diketahui barisan: 2, 5, 8, 11, ... Tentukan U₁₀ dan S₁₀!

Diketahui: a = 2, b = 5 - 2 = 3, n = 10.
U₁₀ = 2 + (10 - 1)(3) = 2 + 27 = 29
S₁₀ = (10 / 2) × (2 + 29) = 5 × 31 = 155

Analisis Persamaan Kuadrat

Bentuk umum: ax² + bx + c = 0

Generator Deret Aritmatika

Menghitung suku ke-n (Uₙ) dan jumlah n suku pertama (Sₙ)
